## Evidence type and limits

- **Live HTTP:** Yes, within the test process. Console endpoint tests start an embedded console on a dynamically assigned loopback port and issue HTTP requests to it. This includes real engine-backed endpoint tests such as backup, query, transaction/bulk, vector, and feature-validation coverage. It is not a browser-driven session or a request to an independently deployed service.
- **Static asset assertions:** Yes. `ConsoleTaskSuccessTest.staticAssetsExposeRequiredAffordances` reads `src/main/resources/static/index.html` and `console.js` from disk and checks their source contents. Those assertions do not render or interact with the browser UI.
- **Browser/live UI:** Not exercised by this command. The pass count is evidence for this focused backend selection only; it does not establish full-suite, browser, or end-to-end readiness.
