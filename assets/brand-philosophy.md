# Layered Core

The identity is built from one quiet shape: three data layers held together by a single spine. The mark should read as a unified engine first, with the individual records visible only on a closer look.

Navy carries the structure; clean white lines define the layers; one gold spine connects them. Keep the palette restrained and the contrast clear at favicon size as well as in a wide banner.

The symbol contains no steam, document, table, or code-brace illustrations. Its meaning comes from alignment and connection, not from a collection of product pictograms. Leave generous open space around the mark and wordmark.

Use the same geometry wherever the identity appears. The banner may add the wordmark and one plain descriptor, but it should remain a clean extension of the icon, with precise spacing and carefully rendered edges.
